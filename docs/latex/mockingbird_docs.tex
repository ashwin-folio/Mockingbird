\section{Introduction}
% =============================================================================

Mockingbird is a design automation pipeline that enables product designers to generate design assets directly in Figma using natural language prompts. The system combines Claude Code (AI orchestration), OpenRouter (image generation), and the Official Figma MCP (canvas manipulation).

\subsection{Key Features}
\begin{itemize}
    \item \textbf{Natural Language Interface}: Describe what you want, get designs
    \item \textbf{AI Image Generation}: Generate backgrounds, illustrations, and visuals
    \item \textbf{Direct Figma Integration}: Compositions appear directly in your Figma file
    \item \textbf{Brand Consistency}: All designs follow your brand guidelines
    \item \textbf{Multiple Use Cases}: Banners, social posts, UI screens, heroes, illustrations
\end{itemize}

\subsection{Target Users}
Product designers with minimal technical knowledge who want to:
\begin{itemize}
    \item Rapidly prototype design concepts
    \item Generate multiple design iterations quickly
    \item Maintain brand consistency across assets
    \item Reduce time spent on repetitive design tasks
\end{itemize}

% =============================================================================

\subsection{Overview}

\begin{verbatim}
+-------------------------------------------------------------+
|                     CLAUDE CODE (Pro/Max)                    |
|              (Orchestration via CLAUDE.md)                   |
|                                                              |
|  +-------------+  +--------------+  +-------------+          |
|  |  CLAUDE.md  |  | Brand Guide- |  | Config YAML |          |
|  |  (Workflow) |  |    lines     |  |  (Settings) |          |
|  +-------------+  +--------------+  +-------------+          |
+-------------------------------------------------------------+
          |                                    |
          v                                    v
+---------------------+              +---------------------+
|   OpenRouter API    |              |  Official Figma MCP |
|  (Image Generation) |              |      (OAuth)        |
|                     |              |                     |
| * Gemini 3.1 Flash  |              |  * use_figma        |
|   Image Preview     |              |  * get_screenshot   |
| * ~$0.10-0.15/image |              |  * get_metadata     |
+---------------------+              +---------------------+
\end{verbatim}

\subsection{Components}

\subsubsection{Claude Code}
The orchestration layer running on the user's machine. Requires a Pro (\$20/month) or Max (\$100/month) subscription.

\subsubsection{OpenRouter API}
Third-party API aggregator providing access to various AI models including Gemini 3.1 Flash Image Preview for image generation.

\subsubsection{Official Figma MCP}
Figma's Model Context Protocol server enabling direct canvas manipulation via OAuth authentication. No additional plugins or servers required.

\section{Installation \& Setup}
% =============================================================================

\subsection{Prerequisites}
\begin{enumerate}
    \item Claude Code Pro or Max subscription
    \item OpenRouter account with API credits
    \item Figma account (Free or paid)
\end{enumerate}

\subsection{Setup Steps}
\begin{enumerate}
    \item Download Mockingbird package
    \item Copy \texttt{.env.example} to \texttt{.env}
    \item Add OpenRouter API key to \texttt{.env}
    \item Run \texttt{claude} in Mockingbird directory
    \item Complete Figma OAuth authentication
\end{enumerate}

\section{Workflow}
% =============================================================================

\subsection{Standard Workflow}

\begin{enumerate}
    \item \textbf{User Request}: Designer provides design direction and use case
    \item \textbf{Analysis}: Claude parses request and determines requirements
    \item \textbf{Brand Loading}: Brand guidelines are loaded for consistency
    \item \textbf{Image Generation}: If needed, images are generated via OpenRouter
    \item \textbf{Iteration Review}: User reviews options in Figma
    \item \textbf{Selection}: User selects preferred iteration
    \item \textbf{Composition}: Final design is created in Figma
\end{enumerate}

\section{Best Practices}
% =============================================================================

\subsection{Prompt Writing}
\begin{itemize}
    \item Be specific about style: ``vibrant gradient'' not ``colorful''
    \item Include purpose: ``summer sale'' not just ``sale''
    \item Reference brand elements: ``use our accent green''
    \item Specify dimensions when needed: ``instagram\_story variant''
\end{itemize}

\subsection{Iteration Management}
\begin{itemize}
    \item Start with 2 iterations (default)
    \item Increase to 3--4 for important assets
    \item Use ``redo'' with feedback for refinement
    \item Clean up unused iterations periodically
\end{itemize}

\subsection{Brand Consistency}
\begin{itemize}
    \item Keep \texttt{brand\_guidelines.md} updated
    \item Use exact hex codes for colors
    \item Specify fonts that are available in Figma
    \item Document tone of voice for copy suggestions
\end{itemize}
