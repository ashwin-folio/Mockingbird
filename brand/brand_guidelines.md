## Typography

### Heading Font
- **Font Family**: Inter
- **Weights**: Bold (700), Semibold (600)
- **Use for**: Headlines, titles, CTAs, buttons

### Body Font
- **Font Family**: Inter
- **Weights**: Regular (400), Medium (500)
- **Use for**: Body text, descriptions, captions

### Font Sizes
| Element | Size | Weight |
|---------|------|--------|
| Hero Title | 48-64px | Bold |
| Section Heading | 32-40px | Semibold |
| Subheading | 24-28px | Semibold |
| Body Large | 18-20px | Regular |
| Body | 16px | Regular |
| Caption | 14px | Regular |
| Small | 12px | Regular |

## Tone of Voice

Our brand voice is:
- **Professional** but approachable
- **Clear** and concise
- **Confident** without being arrogant
- **Helpful** and solution-oriented

**Avoid**:
- Overly casual language
- Jargon without explanation
- Aggressive sales language
- All caps (except for short CTAs)

## Visual Style

### Overall Aesthetic
- Clean and modern
- Generous white space
- Bold typography as focal point
- Subtle gradients when appropriate

### Photography Style
- High-quality, professional images
- Natural lighting preferred
- Diverse representation
- Authentic, not stock-looking

### Illustrations
- Simple, flat design style
- Use brand colors
- Consistent stroke weights
- Geometric shapes preferred

### Backgrounds
- Solid colors from brand palette
- Subtle gradients (primary to accent)
- Abstract geometric patterns
- High-quality photography with overlay

## Logo Usage

### Clear Space
- Minimum clear space: Equal to the height of the logo mark

### Minimum Size
- Digital: 80px width minimum
- Print: 20mm width minimum

### Don'ts
- Don't stretch or distort
- Don't change colors outside brand palette
- Don't add effects (shadows, glows)
- Don't place on busy backgrounds without contrast

### Logo Assets
Place logo files in `brand/assets/logos/`:
| File | Usage |
|------|-------|
| `logo_primary.svg` | Main logo, dark backgrounds |
| `logo_white.svg` | White version for dark backgrounds |
| `logo_black.svg` | Black version for light backgrounds |
| `logo_icon.svg` | Icon-only version (favicon, small spaces) |

## Brand Assets

All visual assets are stored in `brand/assets/` for use in Mockingbird compositions.

### Asset Folders
| Folder | Contents |
|--------|----------|
| `logos/` | Brand logos in various formats/colors |
| `icons/` | UI icons, social media icons |
| `images/` | Stock photos, illustrations, textures |
| `elements/` | Decorative shapes, patterns, overlays |

### Naming Convention
- Use lowercase with underscores: `icon_arrow_right.svg`
- Include variant info: `logo_white.svg`, `logo_dark.svg`
- Include size if specific: `hero_1920x600.jpg`

### Usage in Compositions
Reference assets by name in Mockingbird:
- "Add logo_primary to top-left"
- "Use icon_arrow next to the button"
- "Set hero_photo as background"
